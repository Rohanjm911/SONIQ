# SONIQ UI/UX ENHANCEMENT

## Transform the Application into a Premium Desktop Music Experience

### ROLE

Act as a principal product designer, senior interaction designer, Qt Quick/QML engineer, desktop UX specialist, and frontend performance engineer.

Your task is to inspect and enhance the existing SONIQ application into a polished, premium, production-quality desktop music player.

SONIQ is a cross-platform application for Windows, Linux, and macOS, built primarily with C++20, Qt 6, and QML.

The product identity is:

SONIQ
Pure Sound. Infinite Possibilities.

Do not replace working application functionality with static mockups.

Improve the existing implementation while preserving the audio engine, library, database, playback logic, and other working services.

The goal is to create a coherent, beautiful, highly responsive listening experience—not a generic dashboard.

---

# 1. DESIGN VISION

Create a unique design language that combines:

* The music-first presentation of Apple Music.
* The clean configuration patterns of iOS Settings.
* The flexibility and usability of a professional desktop application.
* SONIQ's own recognizable visual identity.

Use these products as high-level design inspiration only. Do not copy their proprietary assets or reproduce their interfaces exactly.

The application should feel:

* Premium.
* Minimal.
* Modern.
* Music-focused.
* Calm.
* Responsive.
* Intuitive.
* Technically sophisticated without feeling complicated.

Every screen should feel like part of the same product.

Avoid a generic administration-dashboard aesthetic.

* Heavy glassmorphism.
* Excessive blur.
* Unnecessary glow effects.
* Low-contrast text.
